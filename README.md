# Shopping Cart

Shopping cart app built with React and TypeScript.

**Live demo:** https://elvinbaxsh.github.io/shopping-card/

## Features

- Store page with product list
- Add and remove items, change quantity
- Slide-out cart with item list and total price
- Cart state shared across pages with React Context
- Cart items stay after the page is refreshed
- Pages: Home, Store, About

## Tech Stack

React · TypeScript · Vite · React Router · React Context API

## Getting Started

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```
